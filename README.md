# MVY Pending Survey - जिला पंचायत दंतेवाड़ा
### महिला एवं बाल विकास विभाग (WCD), छत्तीसगढ़ शासन

### 🚀 चलाने के तरीके (How to Run):

#### 1. लोकल सर्वर पर चलाएं:
```bash
npm start
```
ब्राउज़र में `http://localhost:8080` खोलें।

#### 2. फाइल्स रीबिल्ड करने के लिए:
```bash
npm run build
```

#### 3. Google Apps Script / Google Sheet में डिप्लॉय करने के लिए:
1. अपनी Google Sheet में **Extensions** > **Apps Script** खोलें।
2. `Code.gs` का कोड पेस्ट करें (Sheet ID पहले से सेट है)।
3. एक नई HTML फ़ाइल बनाकर नाम दें `Index` और उसमें `Index.html` का कोड पेस्ट करें।
4. **Deploy** > **New deployment** > **Web app** (`Anyone`) चुनकर लिंक प्राप्त करें।
